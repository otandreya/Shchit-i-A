# Сайт охранного предприятия

Многостраничный веб-сайт для охранного агентства с каталогом услуг, интерактивным калькулятором расчёта стоимости, информационной статьёй и разделом официальных реквизитов.

## Структура проекта

* `index.html` — главная страница (навигация, первый экран, каталог услуг, калькулятор, форма обратной связи)
* `ohrana.html` — информационная статья о видах охранных услуг и системах безопасности
* `contacts.html` — страница контактной информации и карточки реквизитов организации
* `blocks/` — модульные HTML-фрагменты (`header`, `hero`, `services`, `calculator`, `contact`, `footer`), подгружаемые динамически
* `css/` — раздельные таблицы стилей для каждого модуля и страницы (`style.css`, `header.css`, `services.css`, `calculator.css`, `article.css`, `contacts.css`)
* `js/` — клиентская логика (`main.js`, `calculator.js`, `services-modal.js`, `lucide.min.js`)

## Основной функционал

* **Модульная архитектура:** динамическая загрузка общих элементов интерфейса (шапка, подвал, секции) без дублирования кода.
* **Интерактивный калькулятор стоимости:** расчёт ориентировочной стоимости в модальном окне по трём направлениям:
  * *Пультовая охрана* (площадь, количество помещений и дверей, доп. строения, тревожная кнопка ГБР);
  * *Физическая охрана* (площадь объекта, количество постов, режим работы 12/24 часа, вооружённый пост 6 разряда);
  * *Видеонаблюдение* (тип установки, количество камер, облачный архив и удалённый доступ).
* **Каталог услуг с модальными окнами:** детальное описание 12 видов услуг для бизнеса и частных лиц с автоматической передачей выбранной услуги или расчёта в форму заявки.
* **Адаптивный интерфейс:** корректное отображение на ПК, планшетах и смартфонах, плавная анимация элементов при прокрутке и фиксированная навигационная панель.

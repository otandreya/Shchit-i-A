# Калькулятор стоимости услуг

## Описание
Калькулятор позволяет рассчитать стоимость услуг по пультовой и физической охране на основе различных параметров.

## Функциональность
- Переключение между двумя типами охраны: Пультовая и Физическая
- Расчет стоимости для каждого типа с учетом специфических параметров:
  - Пультовая охрана: площадь, количество комнат, наличие тревожной кнопки ГБР
  - Физическая охрана: количество постов, режим работы (12/24 часа), вооруженный пост 6 разряда

## Использование
1. Нажмите кнопку "Рассчитать стоимость услуг"
2. Выберите тип охраны (Пультовая или Физическая)
3. Установите параметры для выбранного типа охраны
4. Получите расчет стоимости в рублях

## Технические детали
- Адаптивный дизайн с плавными переходами
- Независимый пересчет стоимости для каждого тарифа
- Стилизованные элементы управления (ползунки, чекбоксы)
